LdapRecord aims to provide a simple way to interact with LDAP entries using PHP. The project has released version 3.7.5, which appears to include the following change: Fixed a potential infinite loop in the LdapRecord\Models\Collection::contains method Added the ability to provide additional control options in the LdapRecord\Query\Builder::orderBy method
